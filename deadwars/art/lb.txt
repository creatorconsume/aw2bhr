# Dead Wars: The Last Boat - art source for tools/lbart.py (contract: src/lbart.h).

# Nothing in this file is a pixel grid: tools/lbart.py generates every sprite from these rows
# (the godot-office way: one CAST row per character -> shapes -> tone slots -> outline).
# gfx.py reads every art/*.txt as well, so the data lines start with "#:" (a comment for
# gfx.py) and the one palette block below uses gfx.py's palette syntax.
#
#   python3 -I tools/lbart.py art/lb.txt build/gen        (the Makefile does this)
#   -> build/gen/lbart.c, build/preview/lb_people.png lb_roofs.png lb_icons.png lb_journey.png
