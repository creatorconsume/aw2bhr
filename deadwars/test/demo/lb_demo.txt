# Dead Wars: The Last Boat - demo playthrough for the headless runner (test/gbarun.c).
# Run it with test/demo/run.sh (builds the runner, plays this on fresh SRAM, writes PNGs to
# build/demo/ and checks that no text sits on a window frame).
#
# Route: title -> "The Last Boat" (last item of the title menu) -> New Run on Normal -> the intro
# -> the journey map -> the road to Main Street (a road storylet) -> arrival (a stop storylet) ->
# the stop menu -> Scavenge -> deploy all four -> the mission: moving, searching the house, the info
# card, the START menu, horde turns, Holt's rifle shot (a kill, and the noise brings a wave), June's
# crossbow, leaving by the caravan and the exit -> results -> the mission-end storylet -> camp jobs
# -> the night -> a camp storylet -> the road to Hensley Farm -> its stop menu, the caravan and the
# journal.
#
# Every shot is followed by two VRAM dumps (the text and window layers, SB_TEXT and SB_WINDOW) that
# run.sh checks. The run is deterministic: the run's seed comes from frame_count when New Run is
# picked, and everything after it (storylets, the mission's dice) follows that seed. Changing the
# frames before "New Run", the storylet data or the order of rng calls changes which storylets play
# and where the dead walk: then re-check the shots and adjust the presses below.
# Script commands: see the header of test/gbarun.c ("press K N" holds K for N frames, then 2 more).
